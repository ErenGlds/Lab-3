# Lab-3

# University Course Management System

Run with Node.js 14+:

```
npm start      # or: node main.js
```

## Challenges

- Using ES modules in Node required `"type": "module"` and `.js` extensions in imports.
- Working with the asynchronous callback: all logic had to live inside the callback because the data is only available after the delay.
- For some reason main.js accepts uppercase first letters for "database.js" and "models.js" or else it gives error.
